SMTP listener

25 is standard for relays. Inside Docker, map the host port to this one. Changes restart the listener immediately.
Shown in the SMTP greeting and added to the Received header.
CIDR ranges or single IPs, one per line. Leave empty to accept any address. Only do that together with “Require SMTP AUTH”.

TLS is not enabled yet, so SMTP AUTH passwords are sent in clear text. Use it only on trusted networks or a private link.
Empty network list without SMTP AUTH makes this an open relay. Anyone who can reach the port can send mail as your users.

Enable only behind a load balancer that sends PROXY protocol (e.g. AWS NLB, Cloudflare Spectrum), so the real client IP is used for the allowlist.
Microsoft Graph accepts at most ~3 MB per message and Google 25 MB. Larger messages are refused per destination.
Sender
With Microsoft Graph the sender must be a real mailbox the app is allowed to send as.

Full addresses or @domain, one per line. Empty = any sender.
